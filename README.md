# Cart2Insights: Decoding E-Commerce Performance

## Project Overview

Cart2Insights is an e-commerce data analytics project designed to analyze business performance using customer orders, products, sellers, payments, delivery information, and customer reviews.

The project uses Python, Pandas, MySQL, SQL, and Streamlit to transform related datasets into meaningful business insights through an interactive dashboard.

## Objectives

- Analyze sales and revenue performance.
- Understand customer purchasing behavior.
- Identify top-performing sellers and product categories.
- Evaluate delivery performance.
- Analyze customer reviews and satisfaction.
- Support data-driven business decisions.

## Technologies Used

- **Programming Language:** Python
- **Data Manipulation:** Pandas
- **Database:** MySQL
- **Query Language:** SQL
- **Dashboard:** Streamlit
- **Data Visualization:** Matplotlib, Seaborn

## How to Run the Project

1. Install Python and MySQL.
2. Install the required Python packages.
3. Configure the database connection using your local Streamlit secrets file.
4. Ensure the `ecommerce_db` database and required tables are available.
5. Open a terminal and run:

```bash
cd "Decoding E-Commerce Platform/streamlit"
python -m streamlit run app.py
```

6. Open the local URL displayed in the terminal.
